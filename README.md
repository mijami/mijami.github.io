# Portfolio Website (GitHub Pages)

A simple personal portfolio that runs free on GitHub Pages.

## 1) Create your GitHub Pages repo

Create a **public** repo named exactly:

`<your-github-username>.github.io`

Example: `fahadsid1770.github.io`

## 2) Add files

Upload these files to the root of the repo:

- `index.html`
- `style.css`
- `script.js`

## 3) Push and publish

After pushing, your site is live at:

`https://<your-github-username>.github.io/`

## 4) Customize

Edit `index.html`:
- Replace `Your Name`
- Replace social/profile links
- Replace project cards
- Replace email

Edit colors/layout in `style.css`.
